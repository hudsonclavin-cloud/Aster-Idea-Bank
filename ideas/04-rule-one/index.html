    What it checks
    
    
    A number followed by a unit is attributed to the nearest keyword on its line, counted in tokens, and compared with the keys that keyword names. Words in the sinks list claim a number without checking it. A literal matches canon when canon rounded to the literal's own precision equals it, within 5 % of canon; an integer ending in zeros is read at its last non-zero digit within 3 %. A range passes when it brackets canon. A number that is canon only for a tier its clause does not name (295× at "the 2.5 km/s reference") is a tier finding; a clause that names no tier is read as the reference.
