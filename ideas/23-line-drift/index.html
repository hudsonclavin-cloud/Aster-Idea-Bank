Line Drift

Aster tells every agent to trust STATUS.md first, and its Markdown is full of path:line citations, backticked paths and commit hashes. line-drift.mjs reads 26 of those documents and checks each reference against the checkout: does the path exist and is it tracked and not ignored (the INV-034 test), is the cited line inside the file, and does the code or quote the same sentence pairs with it still sit on that line? It never edits anything. This page is one saved run, with every finding it flagged checked by hand.

        Try it on a passage

        The same linedrift.js the command line uses, run here on text you paste. It starts on the real thing: the Slice 9 amendment (src/v2/SLICE_9_FOUNDING.md lines 423-428) and Aster's .gitignore, both copied at 62ddb17 with provenance under snapshots/. A browser has no git, so tracking, ignore rules and commits are not checked here; only the one file you load can be.

        Run it on a checkout

        node ideas/23-line-drift/line-drift.mjs /path/to/asteroid-mining-planner
node ideas/23-line-drift/line-drift.mjs /path/to/checkout --markdown --allow allow.json --accept-annotated

        Exit 0 when no drift is left un-allowlisted, 1 when some is, 2 when it refuses (no such directory, no documents, an unknown --rev, an allowlist entry without a reason), 3 on a usage error. example.txt is the saved output behind this page; the README says what every number traces to.
