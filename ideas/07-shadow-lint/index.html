Shadow Lint

For every number a FLIGHT loads row feeds its check: can the declared geometry see it? And when a retry moves a number while the geometry stays the same, say which way it moved.

One file

Two files

Only the first pair is an attempt and its retry, and it is synthetic: no recorded PartForge run keeps a failing attempt beside its retry.

Your own file

Paste a flight-grade .scad with a FLIGHT block. Add a second one to diff an attempt against its retry. Nothing leaves this page.

What the classes mean

WITNESSEDThe value equals a declared dimension of compatible unit within that dimension's tolerance: a critical extent, a hole count whose row is a clearance size for the declared thread, a hole at the tap-drill or clearance diameter for that thread. PartForge's mesh CMM measures the declared dimension; this page measures no mesh. DERIVABLEAn arithmetic combination of declared rows: a bore over two (ri_mm), an OD-minus-bore wall over two (t_mm), a feature's from–to span (a through hole's span is the plate thickness; a tapped hole's span is the engagement). UNWITNESSEDNothing declared can see it: a force, a pressure, a speed, an altitude, a strength, a bolt grade or material named in text, a shank in the shear plane; or a length whose candidates all miss (the nearest is named). The tool cannot know such a number is wrong, only that nothing checks it. POLICYsf_min on a hoop, flutter or bolt-shear row: a declared acceptance threshold, not a physical quantity. A retry can lower it with no geometric consequence, which is why the differ watches it. (The thread check ignores sf_min; it is listed as not read.) REFUSEDA key the row lacks, or declares as something the evaluator cannot read as a number, without which PartForge refuses to evaluate the row. ASSUMED means it computes with a default instead (1 bolt, sea level, an 800 MPa bolt); FAILS marks a missing plate thickness, which PartForge turns into a bearing SF of 0. suspiciousIn the two-file view: an input moved the way that makes a check easier (a load lowered, a stronger grade), lost its witness, or was removed. With byte-identical geometry that is a finding. expected is the other way (a load raised to the motor's peak, a missing grade added); no effect means the evaluator reads the same number or does not read the key.
